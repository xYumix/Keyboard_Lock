# Keyboard_Lock
[🇷🇺 Русский](README.md) | [🇺🇸 English](README_en.md)

[![License: PolyForm Noncommercial 1.0.0](https://img.shields.io/badge/License-PolyForm%20Noncommercial%201.0.0-blue.svg)](https://polyformproject.org/licenses/noncommercial/1.0.0)

Этот проект — удобная программа, которая автоматически блокирует встроенную клавиатуру вашего ноутбука (например, HP Omen 15 или любой другой модели), чтобы она не мешала при подключении внешней USB-клавиатуры. Программа работает тихо и сворачивается в системный трей (значок возле часов в правом нижнем углу экрана).

> *This project uses the Interception API (by Oblita), which is licensed under LGPL for non-commercial purposes.*

---

## ⚠️ Важное предупреждение (Не пугайтесь системных окон!)

Поскольку программа управляет реальным железом (отключает клавиатуру на глубоком уровне системы), для её правильной работы **обязательно нужны права администратора**. 

Вам не придется настраивать это вручную — я уже встроил функцию автоматического запроса прав в оба скрипта. 

Поэтому, когда вы будете запускать файлы `check_device_keyboard` или `keyboard_monitor`, экран может потемнеть, и Windows покажет стандартное окно контроля учетных записей с вопросом: *«Разрешить этому приложению вносить изменения на вашем устройстве?»*. 

**Смело нажимайте «Да»!** Это абсолютно нормальное поведение. Без этих прав Windows просто не позволит программе заблокировать вашу встроенную клавиатуру.

## 🛠 Подготовка (Что нужно сделать один раз)

Если вы никогда не работали с программированием и скриптами, не пугайтесь! Просто идите по шагам.

**1. Установка Python (язык, на котором работает программа)**
* Зайдите на официальный сайт [python.org](https://www.python.org/downloads/) и скачайте последнюю версию.
* Запустите скачанный файл.
* **ОЧЕНЬ ВАЖНО:** В самом первом окне установки, в самом низу, обязательно поставьте галочку **"Add Python to PATH"** (или "Add python.exe to PATH"). Без этого программа не запустится! После этого нажмите "Install Now".

**2. Установка (или удаление) драйвера Interception**
* Скачайте этот проект к себе на компьютер (зеленая кнопка Code -> Download ZIP) и обязательно **распакуйте** архив в удобную папку.
* Откройте папку `Install Interception Driver` внутри вашего скачанного проекта. В ней вы найдете два файла для управления драйвером: `install driver` (для установки) и `uninstall driver` (для удаления).
* Для установки запустите файл `install driver` двойным щелчком мыши.
* Скрипт попросит права администратора (смело нажимайте «Да») и автоматически запустит процесс. Черное окно сообщит об успешном завершении.
* **ОЧЕНЬ ВАЖНО: Обязательно перезагрузите компьютер** после установки, иначе драйвер не заработает и клавиатура не будет блокироваться!
* *(Примечание: Если в будущем вы захотите полностью удалить драйвер из системы, зайдите в эту же папку, запустите файл `uninstall driver` и так же перезагрузите компьютер).*

## ⚙️ Настройка программы (Всего 2 шага)

Программе нужно объяснить, какую именно клавиатуру нужно отключать (встроенную), а какую оставить работать (внешнюю). 

**Шаг 1: Узнаем ID (номер) вашей встроенной клавиатуры**
1. Откройте главную папку проекта.
2. Найдите файл `check_device_keyboard` (он может называться `check_device_keyboard.py`).
3. Запустите его двойным щелчком левой кнопки мыши.
4. Появится черное окно (консоль). Нажмите любую кнопку на **встроенной клавиатуре ноутбука** — той самой, которую вы хотите заблокировать.
5. В черном окне появится текст с номером (ID) вашей клавиатуры. Запишите или скопируйте эту цифру. Окно можно закрыть.

**Шаг 2: Вписываем ID в главную программу**
1. В этой же папке найдите второй файл — `keyboard_monitor` (или `keyboard_monitor.pyw`).
2. Нажмите на него **правой кнопкой мыши**, выберите **«Открыть с помощью»** (Open with) и выберите обычный **Блокнот** (Notepad).
3. В открывшемся тексте найдите место, куда нужно вписать ID (там будет написано `INTERNAL_KB_ID = ...`).
4. Осторожно сотрите старую цифру (или пустое место) и впишите туда ту цифру, которую вы получили на Шаге 1. Больше ничего в коде не меняйте!
5. Нажмите в Блокноте `Файл -> Сохранить` (или на клавиатуре `Ctrl + S`) и закройте Блокнот.

## 🚀 Как использовать

Теперь всё готово! 

Просто запустите файл `keyboard_monitor` двойным щелчком мыши. Ваша встроенная клавиатура будет сразу заблокирована, а внешняя продолжит работать. 

В правом нижнем углу экрана (где часы и громкость) появится значок нашей программы. Если вы захотите снова включить клавиатуру ноутбука, просто кликните по этому значку правой кнопкой мыши и закройте программу.

## 📖 История создания (Почему я написал свой скрипт)

Этот проект появился из-за упрямства Windows. Изначально задача казалась элементарной: нужно было просто автоматически отключать встроенную клавиатуру на HP Omen 15 при подключении внешней. 

Поиск готовых решений на GitHub выдавал скрипты, которые пытались отключать устройство «в лоб» — через консольную утилиту `pnputil` или команды для Диспетчера устройств. Но на практике этот путь оказался тупиковым. Windows намертво блокирует программное отключение «критических системных устройств», к которым относится встроенная клавиатура на шине PS/2 или ACPI. Существующие чужие решения выдавали ошибки доступа или просто игнорировались системой.

Раз ОС не давала отключить само железо, я изменил подход и решили глушить его сигналы. С помощью драйвера `interception` на уровне ядра и библиотеки `ctypes` я научил скрипт распознавать уникальный аппаратный ID встроенной клавиатуры и физически блокировать её нажатия. Внешние USB-устройства при этом остаются нетронутыми. В результате получилась эта легковесная программа с иконкой в системном трее, которая делает ровно то, что нужно.
